# <h1>AspNetCoreMVC-CRUD</h1>

A CRUD (Create, Read, Update, Delete) web application developed using C#, ASP.NET Core MVC, ADO.NET, and SQL Server. The project demonstrates fundamental web development concepts, database connectivity, and data management in ASP.NET Core MVC.

<img width="1307" height="450" alt="Table" src="https://github.com/user-attachments/assets/13de96c6-c013-4790-b80d-dde1808267d6" />

🚀 Technologies Used

Backend: C#, ASP.NET Core MVC

Database: Microsoft SQL Server

Data Access: ADO.NET

Frontend: HTML, CSS, JavaScript

UI Framework: Bootstrap

Development Environment: Visual Studio

✨ Features

Create new records

View and display records

Update existing records

Delete records

Connect to SQL Server using ADO.NET

Build responsive user interfaces with Bootstrap

Organize application code using the MVC pattern
📚 What I Learned

Understanding the ASP.NET Core MVC architecture

Performing CRUD operations with ADO.NET

Connecting an ASP.NET Core application to SQL Server

Working with controllers, models, and Razor views

Creating web interfaces using Bootstrap, HTML, CSS, and JavaScript

🔮 Future Improvements

Add input validation and improved error handling

Improve the user interface and responsiveness

Add search, filtering, and pagination

Implement authentication and authorization

Refactor the code and improve maintainability
